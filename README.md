# 🛡 sing-bounds

**Простой VPN-сервер на вашем OpenWrt-роутере**

Интернет «как дома» из любой точки мира — без подписок и платных сервисов.
Сервер — ваш собственный роутер.

## 🚀 Установка

Подключитесь к роутеру по SSH и выполните **одну команду**:

```sh
wget -qO- https://raw.githubusercontent.com/Boomerokk/sing-bounds/main/install.sh | sh
```

После установки: **веб-панель роутера → Службы (Services) → sing-bounds → «Создать туннель»**

<details>
<summary><b>Что делает установщик</b></summary>

1. Проверяет, что это OpenWrt и что есть интернет
2. Доустанавливает нужные мелкие пакеты (если не хватает)
3. Проверяет движок **sing-box**: уже стоит — не трогает; нет — ставит
4. Копирует файлы sing-bounds, включает автозапуск, запускает сервис

Ничего существенного на роутере не удаляется и не перенастраивается.
Повторный запуск — просто обновление: туннели и клиенты сохраняются.

</details>

<details>
<summary><b>Удаление</b></summary>

Кнопка в LuCI (**Система → Удалить sing-bounds**) или команда на роутере:

```sh
ubus call singbounds uninstall
```

Удаляется всё, что поставил sing-bounds: файлы, конфигурация, правила firewall, сервис.
Сам OpenWrt и sing-box (если были) не трогаются.

</details>

<details>
<summary><b>Резервные копии</b></summary>

После каждого изменения (создание/удаление туннеля или клиента) sing-bounds
автоматически сохраняет снимок конфигурации — **5 последних** лежат в
`/etc/sing-bounds/backup/uci/`. Если что-то пошло не так, любой снимок можно
вернуть:

```sh
cp /etc/sing-bounds/backup/uci/config.<дата> /etc/config/singbounds
/etc/init.d/singbounds restart
```

</details>

## 📖 Как это работает

**Простыми словами:** вы дома нажимаете «Создать туннель» — получаете QR-код.
Человек в отеле или в другой стране сканирует его приложением — и его телефон
подключён к вашему домашнему интернету.

## ✨ Возможности

| | Возможность | Пояснение |
|---|---|---|
| 🔐 | **VLESS + Reality** | Современный протокол: трафик неотличим от обычного HTTPS к популярному сайту |
| 📱 | **QR-код и ссылка** | Скан — и подключено. Работает с Happ, v2rayN, Streisand и другими |
| 🖼 | **Мини-QR в списке** | У каждого клиента — маленький QR справа от ссылки: клик — и код открывается крупно |
| 👥 | **Клиенты** | Каждому — свой ключ (UUID); включение/отключение одним кликом |
| 🌐 | **Виртуальные IP** | Подключённый видится в домашней сети как отдельное устройство — для него можно настроить firewall или обход блокировок |
| ⚙️ | **Всё в LuCI** | Отдельная админка не ставится: только стандартные механизмы OpenWrt |
| ↩️ | **Откат конфига** | Если новый конфиг не поднялся — автоматически возвращается рабочий |

## 📱 Подключение (пошагово)

```
1. Установите приложение: Happ (iOS/Android) или v2rayN (Windows)
2. В sing-bounds раскройте карточку клиента → кликните мини-QR (или кнопку «QR»)
3. Отсканируйте QR в приложении
4. Нажмите «Подключить». Готово! 🎉
```

> 💡 **Совет:** QR можно скачать как большую PNG-картинку (1080×1080) —
> удобно отправить в мессенджере. Или переслать текстовую ссылку
> кнопкой «Копировать ссылку».

## ⚠️ Статус функций

| Функция | Статус |
|---|---|
| VLESS + Reality (туннели, клиенты, QR) | ✅ **стабильно** — проверено на живом роутере |
| Tailscale (mesh-сети) | 🧪 **экспериментально** — на живых сетях не проверялась |

> 🧪 **Про Tailscale:** в окне «Создать туннель» есть второй тип —
> Tailscale (Routerich / аккаунт Tailscale / свой headscale-сервер).
> Код не тестировался на реальных сетях — возможны ошибки. Если нужен
> гарантированно работающий VPN, пользуйтесь типом **VLESS**.
> Для Tailscale сначала установите пакет (~26 МБ) в «Настройках».

## 🧰 Требования

| Требование | Пояснение |
|---|---|
| **OpenWrt 24.10+ / 25.x** | старые версии не проверялись |
| **root по SSH** | для команды установки |
| **sing-box ≥ 1.12** | не установлен — поставится автоматически |
| **Внешний («белый») IP** | без него подключиться извне не получится |
| **~10 МБ памяти** | + ~45 МБ, если sing-box ещё не установлен |

**Проверено на:** OpenWrt 25.12.1 · Cudy WR3000S · sing-box 1.13.x

## ❓ Частые вопросы

<details>
<summary><b>Это безопасно?</b></summary>

Соединение шифруется современным протоколом; ключи генерируются на роутере
автоматически. Доступ к панели — под вашим паролем LuCI. Ссылку-приглашение
знаете только вы и те, кому её отправили.

</details>

<details>
<summary><b>Провайдер увидит, что это VPN?</b></summary>

Трафик маскируется под обычный HTTPS-запрос к легитимному сайту (это и есть
«Reality»). Отличить его от обычного сайта по подписи крайне сложно.

</details>

<details>
<summary><b>Сколько людей можно подключить?</b></summary>

Роутер не упрётся в десятки клиентов. Но помните: все они делят канал вашего
домашнего интернета.

</details>

<details>
<summary><b>Чем это отличается от платного VPN-сервиса?</b></summary>

Тем, что сервер — ваш собственный роутер, а не чужая компания. Никто не ведёт
логи, не ограничивает скорость и не требует подписку.

</details>

## 📂 Структура репозитория

```
install.sh     — установщик (запускается на роутере, одной командой)
Makefile       — рецепт сборки пакета OpenWrt (.ipk/.apk)
files/
  backend/     — логика: состояние в UCI, firewall, виртуальные IP, сборка конфига
  rpcd/        — мост между LuCI и backend (ubus-методы)
  init.d/      — скрипт автозапуска сервиса
  acl.d/       — права доступа для LuCI
  menu.d/      — пункт меню в веб-панели
  www/         — приложение LuCI (страница sing-bounds)
```

<details>
<summary><b>📦 Установка пакетом .ipk/.apk</b></summary>

Помимо установщика одной командой, в репозитории есть рецепт сборки пакета
OpenWrt (`Makefile`). Скопируйте репозиторий в `package/` своего SDK
(или подключите как feed) и соберите:

```sh
make package/luci-app-singbounds/compile V=s
```

Установщик-скрипт и пакет эквивалентны; пакет — для тех, кто предпочитает
штатный opkg/apk-менеджмент.

</details>
